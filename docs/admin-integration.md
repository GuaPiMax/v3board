# 第三方订阅完整后台整合

## 使用

登录原后台，在「服务器 → 第三方订阅」管理来源、选择套餐、启用/停用和手动同步。在「财务 → 订阅管理 → 编辑订阅」选择多个第三方来源。两边修改同一张关联表，不需要第二次登录。

旧地址 `/后台路径/external-subscriptions` 自动跳转至 `/后台路径#/external-subscriptions`。原独立登录页已移除。API 继续使用本站 admin 中间件；列表不回显订阅 URL，编辑时空链接表示保留。

本次不增加数据库结构，不清理既有来源、套餐或缓存。套餐保存和绑定变更在同一事务中完成。旧客户端不传绑定字段则保留绑定，传空数组才解绑。来源 revision 与套餐绑定指纹共同防止两边旧表单互相覆盖；冲突返回 409，重新打开编辑即可获取最新状态。

第三方节点下发、30 分钟同步、24 小时失败缓存和套餐资格规则保持原有设计。套餐到期只停止下发；本站无法使第三方已分发的普通节点凭据失效。

## 已安装站更新

先按日常方式备份数据库、`.env` 和 `config/v2board.php`，然后运行：

```bash
su -s /bin/bash www -c 'cd /www/wwwroot/console.v3board.top && PHP_BIN=/www/server/php/84/bin/php bash update.sh'
```

完成后在宝塔重载 PHP 8.4，并用浏览器强制刷新后台。保留现有 PHP-FPM、Redis、Horizon 与调度配置，不需要重新安装或配置 Node。服务器有受 Git 跟踪的本地修改时，update.sh 会停止，先备份并处理冲突。
