# 第三方节点名称前缀

用户已确认：来源独立设置，允许相同前缀；直接拼接原名；空值保留原名；保留前后空格；修改后无需同步；仅完整名称冲突时追加 (2)、(3) 序号。原生节点名优先保留。

实现采用可重复执行的增量迁移增加 node_prefix（默认空字符串，100 字符），安装和更新命令自动执行。旧 API 客户端省略字段时保留原值，显式空值清除。前缀不允许控制字符和 Unicode 换行符，避免生成行式订阅注入。前缀仅在读取加密节点快照时应用，不污染快照或凭据；元数据缓存键包含名称哈希。输出统一处理重名，保留最初显示名以避免多次过滤重复加序号。复用现有各客户端的编码和不兼容参数过滤。

检查包括真实管理员 API 的保存/读取/旧客户端/空格/清除/恶意输入，URI、VMess、YAML 输出，重复命名、原生名称冲突、缓存失效、快照与凭据不变，以及新装和旧数据库升级。
