# 第三方订阅完整后台整合

用户已选择完整整合：原后台菜单、布局、登录状态；来源 CRUD、启停、手动同步、同步状态；套餐与来源双向多选绑定。

## 实现

- 引入当前构建版本对应的 React 源码到 frontend/admin，保留上游许可证及版本记录。复用原有 Ant Design、请求、权限与布局，不增加前端依赖。服务端继续提供已构建资源，部署不需要 Node。
- 新增「服务器 → 第三方订阅」；沿用列表与抽屉。链接用密码输入框且不回显，空值表示保留；同步结果使用文本渲染。来源编辑保持原有 revision 并发检测。
- 套餐保存的可选 external_subscription_ids 在同一事务内更新绑定。旧客户端未传字段则保留绑定。空数组明确解绑。绑定指纹防止旧套餐表单覆盖来源侧修改；绑定变更提升来源 revision，防止旧来源表单覆盖套餐侧修改。
- 原独立管理地址跳转到原后台 hash 路由，沿用原登录凭据。保留节点同步、资格判断、缓存失效与客户端输出逻辑。
