# 第三方节点关键词过滤

用户确认：每来源单独设置多个关键词；匹配原始节点名，包含任意一个即过滤；英文不区分大小写；前缀不参与匹配；保存后下次获取立即生效，不需同步。

新增 nullable JSON 文本字段 filter_keywords，旧来源 null 表示不过滤。API 仅接受最多 50 个关键词的列表，每个 1–100 字符，去除外围空格（原请求中间件）、拒绝控制字符，显式空数组清空，省略保留，沿用 revision 乐观锁。界面使用原组件的 tags 多选，不引入依赖。节点数标明是过滤前的同步节点数。

过滤在 Subscriptions::nodes 读取快照后、前缀与重名处理前完成，网页 metadata 和各客户端共享此入口。保留原节点 ID，过滤节点不计入 3000 个下发上限；不修改加密快照，清空即恢复。非法存储规则跳过该来源，避免错误时意外下发被屏蔽节点。普通字符串匹配，不支持正则表达式。

安装与更新自动运行独立增量迁移。检查 API 保存/读取/空值/旧客户端/校验/鉴权，中文和大小写、多词 OR、前缀顺序、来源隔离、清空恢复、全量过滤、元数据与订阅输出、旧站迁移和数据保留。
