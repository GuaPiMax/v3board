# 第三方订阅节点名称前缀

原后台「服务器 → 第三方订阅 → 添加/编辑 → 节点名称前缀」。每个来源独立设置，可使用相同前缀。`备用` + `香港A` 输出 `备用香港A`；空值保留原名，不再添加旧的自动「外部 ID-序号」标签。前后空格保留，不自动加分隔符。

保存后用户下次获取订阅生效，无需同步。前缀不写入节点快照，不改变连接凭据或流量规则。只在完整名称冲突时为第三方节点追加 ` (2)`、` (3)`，优先保留本站原生节点名。不同客户端过滤不支持的协议后分别处理重名。最多 100 字符，拒绝控制字符和换行；其他特殊字符仍按现有客户端兼容规则处理。

现有站按原方式备份数据库和配置后执行 update.sh，再重载 PHP、刷新后台。安装器和更新器自动执行新增的 `2026_11_13_000002_add_external_subscription_node_prefix.php`，旧来源默认空前缀，不清空数据。旧管理客户端省略字段时保留当前值，显式空字符串清除前缀。
