# 部署后主动复查

范围：框架升级后的鉴权/权限、缓存、主题/部署流程、第三方订阅解析、来源读取、安装与历史升级。不是对所有第三方支付、主题和供应商的完整认证，也不表示不存在未知缺陷。

## 已复现并修复

1. **会话撤销与权限变化延迟（高）**：原鉴权直接复用最长一小时的身份缓存，移除单个会话后仍可能通过校验；封禁/权限变化也可能复用旧结果。先以测试复现，再改为每次验证签名、会话存在性和当前账号状态。旧缓存不再作为鉴权依据。保持 JWT 格式兼容，不需要换 APP_KEY；代价是每次已认证请求增加一次账号查询。
2. **短暂后端故障引发强制退出（中）**：缓存/数据库异常原先被转成无效身份，前端会在 403 时清掉令牌。现在有效 JWT 的后端故障返回泛化 503，便于稍后重试；无效令牌仍被拒绝。登录保存会话失败也返回 503，不返回无法使用的成功令牌。
3. **并发会话覆盖（中）**：新增、撤销、全部撤销会话的读改写使用同一用户缓存锁，降低同时登录/退出时互相覆盖的风险。锁不可用不会放宽认证。
4. **来源较多时的快照内存占用（中）**：原先在达到 3000 节点上限前已加载全部来源快照。改为按 ID 每次读取一个来源，到达上限即停止。测试用五个千节点来源验证只读取必要的批次。
5. **订阅解析健壮性（低/中）**：支持普通及 Base64 内容中的 UTF-8 BOM；拒绝无效 UTF-8 节点字段，避免单个非法名字拖累整份 JSON 快照；校验 SS 2022 密钥长度与 Reality 公钥/short ID，拒绝不支持的 VMess 安全参数。
6. **root 更新后的权限回退（中）**：宝塔 root 运行 update.sh 成功后恢复 www 所有权，与 init.sh 一致。推荐仍以 www 运行部署命令。

## 新增部署自检

```bash
su -s /bin/bash www -c 'cd /www/wwwroot/console.v3board.top && /www/server/php/84/bin/php artisan v3board:doctor'
```

检查 PHP/扩展、.env 可读性、APP_KEY 格式及与文件的一致性、主题/视图/缓存/日志权限、持久缓存、缓存读写与锁、数据库和关键表、后台与 Horizon 路由、队列配置。只在缓存中创建并清理独立随机测试键，不修改业务配置，不输出密码、密钥、JWT 或订阅链接。

该命令检查 CLI 与执行用户；不能检测 Nginx 是否仍转发到 6600，也不能代替 PHP-FPM 的配置/权限、Supervisor 是否运行、计划任务是否按时触发。运行结果 FAIL 需要按具体项处理，不应清空 Redis、重装数据库或重新生成 APP_KEY。

## 验证结果

- PHPUnit：14 个测试、60 项断言通过，包括会话撤销、管理员降权、封禁、拒绝伪造缓存身份、缓存写失败和暂时不可用、自检不泄漏密钥。
- 第三方订阅独立回归：130 项检查通过，包括真实签名令牌的管理 API、五个大来源的读取边界、解析异常、原有客户端生成器对照。
- 独立 MariaDB：完整安装 39 张表、管理员创建、配置缓存、第三方迁移、拒绝覆盖安装、重复历史升级和统计数据保留通过。
- 无开发依赖目录的订阅回归单独执行；依赖审计无已知安全公告/废弃包；Composer 严格验证通过。293 个 PHP 源文件完成语法检查（新增文件后最终计数以检查输出为准）。

## 仍需服务器验收

我没有用户服务器的远程访问能力，无法直接验证实际 PHP-FPM 配置、宝塔权限、反向代理、Redis 部署策略、Supervisor 和 cron 的运行状态。没有真实支付商户、SMTP 或第三方订阅账号，未执行真实扣款、发信和节点连接。长时间并发/容量压测、全部客户端版本导入、自定义主题和任意未来上游合并不在本轮测试覆盖内。

建议先用测试套餐完成添加来源→同步→购买/开通→下载订阅→客户端连接，再验证耗尽流量/到期/封禁时不再下发第三方节点；支付和邮件先用测试环境。不要把测试通过当作全站无漏洞保证。
