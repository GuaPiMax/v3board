# 第三方节点关键词过滤

入口：原后台 → 服务器 → 第三方订阅 → 添加/编辑 → 过滤关键词。输入关键词后按回车，可设置多个，也可粘贴多行。

以每个来源的原始节点名作普通包含匹配，命中任意一个即过滤。英文不区分大小写，中文正常匹配，句点等符号当普通字符，前缀不参与匹配。最多 50 个，每个 100 字符；自动去掉外围空格。清空全部关键词恢复下发。保存后用户下次更新订阅及网页节点列表即生效，不需要重新同步。原生节点、其他来源、节点凭据和快照保持原行为。已下载到用户客户端的节点需更新订阅后才移除。

来源列表显示过滤关键词；「同步节点数」表示过滤前的可解析节点数。全部节点命中时，该来源本次下发为空，不回退到旧的未过滤缓存。
